# 拼豆图纸生成器 · 功能规格

> 活文档：描述「现在怎么工作」。修改功能前必读；实现变化必须跟随更新。
> 决策历史见 `docs/requirements/拼豆图纸生成器.md`（已冻结）。

## 1. 现状概览

单页 React 应用 + 本地 Express 后端。前端完成图片解码、网格采样、颜色量化、优化、图纸渲染与全部导出；后端只做账号认证与 `Pattern` 工程数据持久化。图片从不离开浏览器。

- 开发：Vite 5173，`/api` 代理到 Express 3001
- 生产：`npm run build` 后 `npm start`，Express 同时托管 `dist/` 与 `/api`

## 2. 数据流

```
File / 拖拽 / 粘贴
 → createImageBitmap → Canvas → ImageData（>4000px 降采样）
 → [可选] 浏览器内 ISNet 去背景 → 透明 ImageData
 → sampleGrid：每格取量化直方图众数；alpha<128 或与四角背景色相近 → null
 → quantizeGrid：rgb→Lab，CIEDE2000 找所选色板最近色；可选 Floyd–Steinberg 抖动
 → optimizeGrid：limitColors → mergeSmallRegions → removeIsolated
 → createPattern → React state
 → drawGrid（Canvas 预览）/ renderPatternPng / exportPatternPdf / GuideView
 → localStorage 草稿；登录后 POST /api/patterns
```

转换在 `App.tsx` 的 `useEffect` 中执行，用 `requestRef` 递增的 requestId 丢弃过期结果；40ms 延时让 loading 态先渲染。参数、色板、豆径变化自动重算；有手工修改时先弹确认。

## 3. 公共契约 `Pattern`

`src/core/types.ts`。`cells: (string|null)[]` 存**色号**而非 HEX，长度恒为 `w*h`，行优先；`null` = 不放豆。`progress: boolean[]` 与 `cells` 等长。`version` 每次修改自增，`updatedAt` 为 ISO 字符串。

工程文件即该对象的 JSON（`core/pattern.ts` 的 `serialize` / `parsePattern`，导入时校验长度与格子类型）。

## 5. 后端 API

认证：scrypt 密码哈希 + HMAC-SHA256 JWT（httpOnly cookie `wedou_session`，30 天）。密钥首次启动时生成并存于 `server/data/secret`。

| 方法 | 路径 | 行为 |
|---|---|---|
| POST | `/api/auth/register` | 用户名 2–32 位、密码 ≥6 位；重名返回 400 |
| POST | `/api/auth/login` | 校验后写 cookie |
| POST | `/api/auth/logout` | 清 cookie |
| GET | `/api/auth/me` | 返回当前用户或 `null` |
| GET | `/api/patterns` | 未登录 401 |
| POST | `/api/patterns` | upsert；校验 `w/h ≤ 300` 与 `cells.length === w*h`；云端版本更新时返回 409 并带云端对象 |
| DELETE | `/api/patterns/:id` | 删除 |

存储：`server/data/users.json` 与 `server/data/patterns/<userId>.json`，同步读写，无原生依赖。仅适用于本地/单机运行。

## 6. 状态与边界

状态：`empty → loading → ready/exporting → error`。导出中禁用编辑按钮；切色板/改参数/点重新生成在 `dirty` 时弹二次确认；AI 分割是独立任务，失败只提示不破坏已有网格。

| 情形 | 现行为 |
|---|---|
| 非图片文件 | 明确提示「请选择图片文件」 |
| 原图 >20MB 或 >4000px | 降采样并提示 |
| 网格 >200×200 | 输入框上限 200，后端上限 300 |
| 全透明 / 纯背景图 | 全部格子为 `null`，用量表显示「暂无用豆」 |
| 色数超上限 | 稀有色合并到最接近的常用色，并提示合并数量 |
| 色卡数据异常 | 抓取脚本按色数校验，失败即以非零码退出 |
| AI 模型/CDN 不可用 | 提示「智能去背景不可用…可用橡皮手动擦除」，图纸保留 |
| localStorage 配额满 | 静默跳过写入，内存副本本次会话仍可用 |
| 云端 409 | 提示「云端版本较新，本地副本已保留」 |
| 未登录 / 登录态过期 | 本地草稿继续可用，登录按钮可用 |

## 7. 导出规格

- **PDF**：jsPDF 动态加载，A4 纵向，边距 12mm，格子 6.4mm（29 格 = 185.6mm）。每块 29×29 板一页，页内含板编号、`R… / C…` 全局坐标、格内符号、每色号颗数。PDF 内文字全为 ASCII（jsPDF 内置字体无中文），标题里的中文会替换为 `BEAD CHART`。
- **PNG**：`renderPatternPng`，格子 26px，含坐标、符号、用量表与统计，整图单文件。
- **工程 JSON**：`serialize(pattern)`，可由图纸库导入。

空格在两种图纸里都画成浅底 + 小圆点，并在图例注明 `EMPTY CELLS = NO BEAD`。

## 8. 色卡数据

`src/data/palettes.json`：来源 bitbead.app 公开色卡页，抓取日期见文件内 `fetchedAt`。5 套共 894 色（221 / 291 / 117 / 89 / 176）。`scripts/fetch-palettes.mjs` 从 Next.js RSC 负载提取 `code/name/hex` 三元组，并校验与页面 `numberOfItems` 一致；请求间隔 400ms。

HEX 为参考值，不等同实物色；界面多处明示，图纸依赖色号与符号。

## 9. 前端规范落地

CSS 全部走 `styles.css` 的变量体系（`--font-size` 基准、语义色、间距/圆角/阴影 token）；图标只用 lucide-react；二元状态用 Toggle Switch；221 色的选择用带搜索列表；列表表头与数据行共用 `.table-head` / `.table-row` 列模板；弹窗统一 `.modal-mask` 基类，子级用 `.nested` 提高层级；所有可点击元素有 hover；顶栏在 900px / 560px 两档断点重排，登录入口在手机端仍可见。
