# 拼豆图纸生成器 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.
> 本会话执行方式：用户已明确「一次性做完」，按用户级《AI 协作规范》连续执行，不询问执行选项、不在阶段间索要确认。

**Goal:** 交付一个可运行的拼豆网站：用户上传图片 → 选色板/尺寸 → 生成带色号图例与坐标的图纸 → 手工编辑 → 导出 A4 分页 PDF / 高清 PNG / 网页拼装引导 → 登录后跨设备同步图纸与进度。

**Architecture:** 纯前端完成图片解码、量化与全部渲染，图片不出浏览器；AI 去背景用浏览器内 ONNX 模型（CDN 动态加载，失败降级手动擦除）；Node/Express 后端只存账号与 `Pattern` 工程数据（JSON 文件，无原生依赖），不存原图。前后端唯一契约是 `Pattern` 对象。Vite dev 用 `/api` proxy，生产由 Express 托管 `dist/`。

**Tech Stack:** TypeScript + React 18 + Vite 6、lucide-react、jsPDF、Express 4、Node `crypto`（scrypt + HMAC-SHA256 JWT）、Vitest。色卡数据由 `scripts/fetch-palettes.mjs` 从公开色卡站批量提取生成 `src/data/palettes.json`。

**规范约束:** CSS 全部走变量体系（`--font-size` 基准、语义颜色、间距/圆角/阴影 token）；图标只用 Lucide；二元状态用 Toggle；7+ 选项用带搜索下拉；禁止 Grid/Flex 与 absolute 混用；弹窗统一基类控制层级；所有可点击元素有 hover；列表有表头且列模板一致。图纸内文字一律英文/数字/符号，避免 jsPDF 中文字体缺字。
