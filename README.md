# 微豆 · 拼豆图纸工坊

把一张图片变成能照着拼的拼豆图纸：格内直接标色号（A1、C10…）、每 5 格一条粗定位线、行列坐标、每色号用量与占比、29×29 分板打印，以及边拼边看的网页引导。

图片全程只在浏览器里处理，不会上传；账号云端只保存网格工程数据和拼装进度，不保存原图。

## 在线访问

- **完整版（推荐）**：https://wedou.sherlockguo.com/ —— N150 常驻 Node 服务，账号注册/登录、云端图纸同步、拼装进度跨设备全部可用
- **静态镜像**：https://sherlockguo-yc.github.io/WeDou/ —— GitHub Pages 纯前端，转换/编辑/导出功能相同，但没有后端，页面显示「本地模式」，换设备请用「工程文件」导出再导入

两者都由 push 到 `master` 自动部署：静态版走 `deploy.yml`（Pages），完整版走 `deploy-n150.yml`（GitHub Release → webhook → N150 deploy-agent）。**完整版不需要任何 R2 Secrets**：N150 实测直连 GitHub 为 200 / 0.6s，Release 兜底即可。

## 快速开始

```bash
npm install
npm run dev        # 前端 http://localhost:5173
npm run server     # 后端 http://localhost:3001（另一个终端）
```

开发模式下 Vite 把 `/api` 代理到 3001。生产运行：

```bash
npm run build
npm start          # Express 同时托管 dist/ 与 /api
```

常用命令：

| 命令 | 作用 |
|---|---|
| `npm test` | 核心算法 + 渲染层绘制单元测试（Vitest） |
| `npm run build` | TypeScript 检查 + Vite 构建 |
| `npm run fetch:palettes` | 重新抓取色卡数据，写入 `src/data/palettes.json` |

## 功能

- 上传 / 拖拽 / 粘贴图片；**先分析长宽比并按原比例推荐网格尺寸（1:2 → 21×42），确认参数后点「生成图纸」才出图**；可锁定比例让宽高联动；可选浏览器内 AI 去背景（ONNX + ISNet，模型按需下载，失败自动降级手动擦除）
- 7 套真实色板（**默认 MARD 221**）：MARD 221 / MARD 291 / Perler 117 / Hama 89 / Artkal 176 / Artkal Mini 221 / COCO 291；Lab + CIEDE2000 最近色匹配；同色不同号会标出，近似替代格数会提示
- 限色、去孤立豆、小区域合并、可选抖动；透明区自动留空；可选「自动抠纯色背景」（默认关，只删连到画面边缘的纯色背景，渐变背景不会误删主体）；「保留细线细节」默认开，找回眼睛、发丝、描边，照片噪点多时可关
- 「3 · 定图纸」的 7 个开关记住上次选择（仅存浏览器本地，不上传）；刷新或重开页面无需重勾，尺寸仍按每张原图比例重新推荐，打开旧图纸时以图纸自身参数为准
- 点格改色、拖拽刷色、橡皮、吸管、**区域换色**（选中色号后一次性换成另一色号，或全部留空不放豆）、撤销重做（50 步）
- 导出按 29×29 分板的 A4 PDF（每页右上角有拼接示意，标出本页是整张图的哪一块；板数多时可输入起止板号分批导出）、高清 PNG、工程 JSON
- 网页拼装引导：**按色号高亮为主流程**（点色号一次只拼一种颜色、显示剩余颗数），配 29×29 板切换 + 当前板红框 + 只看当前板 + 隐藏已完成、点格标记完成、进度持久化；导出的 PNG / PDF 始终是完整全彩图纸
- 跨品牌单色替代建议（按色差自算）
- 本地草稿 + 账号云同步（SQLite + 一次性恢复码找回密码 + 6 小时自动备份）；草稿按账号隔离，切换账号不会看到别人的图纸；不登录也能完整使用转换与导出
- **图纸仓库**：只属于自己的私人图纸，带预览图的卡片网格、按名称搜索、重命名、复制、删除、导入工程
- **图纸市集**：把仓库里的图纸发布成公开快照，所有人（含未登录访客）可浏览、按名称/作者搜索；作者可撤销，登录用户可另存为自己的独立副本。发布时名称必填且不能是「未命名图纸」；预览图由浏览器按色号生成，原图从不上传。静态版本地模式隐藏市集入口

## 色卡数据

`src/data/palettes.json` 由 `scripts/fetch-palettes.mjs` 从公开的 bitbead.app 色卡页批量提取（7 个请求，1406 色），含色号、名称、HEX、来源 URL 与抓取日期。脚本会校验每个色板的色数与页面声明一致。DMC 页面是绣线↔拼豆色号对照表、不是可购买的拼豆套装，因此没有纳入色板。

**HEX 是公开参考值，不是厂商分光实测值**，批次染色会有偏差。图纸以格内色号为准，不要按屏幕或打印颜色配豆。

> 数据来源为 bitbead.app 等公开色卡整理站（`palettes.json` 内记录了每套色板的来源 URL 与抓取日期），**非品牌官方数据**，仅用于色号对照与图纸生成。与其它公开色卡交叉比对时约 17–20% 的色号存在明显色差（ΔE>5）；实际配色请以手上的豆子为准。

## 结构

```
src/core/        网格数据模型、色差、量化、优化、分板、统计、AI 分割、开关偏好
src/render/      Canvas 网格、PNG、A4 分页 PDF、缩略图
src/components/  通用控件、图纸画布、用量表、替代建议、预览图
src/views/      工作台、拼装引导、图纸仓库、图纸市集、登录
src/api/        后端 API 客户端（私有图纸 + 公开市集）
server/         Express 账号认证、工程数据与图纸市集持久化（sql.js / SQLite）
scripts/        色卡抓取
tests/          核心算法测试
docs/           需求文档（冻结）、功能规格（活文档）、实现计划
```

技术栈：TypeScript + React 18 + Vite 6、lucide-react、jsPDF（动态加载）、Express 4、sql.js（WASM SQLite，无原生编译）、Node `crypto`（scrypt + HMAC-SHA256 JWT）、Vitest。

## 约束与边界

- 完整版部署在 N150（端口 3002，`~/wedou`），产物不含 `node_modules`，由 `scripts/restart-n150.sh` 现场安装到 `~/wedou-deps` 并软链接回来；该脚本用 `flock` 串行化且后台进程带 `9>&-`，避免死锁阻塞全局部署队列。
- 静态版由 `.github/workflows/deploy.yml` 构建（`VITE_STATIC_MODE=1`、`--base /WeDou/`）。
- 不含第三方登录、付费；图纸市集只公开图纸网格、名称、作者名与预览图，不含评论/点赞/审核后台，也不上传原图。
- 市集数据存在 `market_items` 独立表（发布/撤销才写，浏览只读）；静态版没有后端，因此隐藏市集入口并提示本地模式。
- 账号数据落在 `server/data/wedou.sqlite`（已 gitignore，受部署脚本的 `data` 排除规则保护）；每 6 小时自动快照到 `server/data/backups/`，保留最近 10 份。旧 JSON 数据首次启动会自动迁移。适合小团队自用，不是多实例高并发方案。
- 忘记密码凭注册时的一次性恢复码（16 字符），服务端只存哈希，不引入邮件服务或第三方账号；重置成功后旧码作废并生成新码。
- AI 去背景首次使用需从 CDN 下载约 40MB 模型；无网络或设备不支持时会提示并回退到手动擦除，不影响主链路。可用 `VITE_BG_MODULE_URL` / `VITE_BG_MODEL_BASE` 指向自托管的模块与模型目录，无需改代码。
- 网格上限 200×200，原图超过 4000px 或 20MB 会先降采样。
- PDF 的中文图纸标题由浏览器系统字体渲染成 3 倍分辨率位图嵌入（任意汉字都支持、体积几乎不变，但该行不可选中/搜索）；纯英文标题保持可选文字。坐标、色号、统计等标注仍是英文/数字/符号。
